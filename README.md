# Clear Copy

Windows 原生剪贴板清洗工具。纯 C + Win32，无 GUI 框架、无网络请求、无剪贴板历史记录。

## 使用

运行 `dist/clear-copy.exe` 后，程序驻留在右下角托盘（可能在隐藏图标区域）。

- 复制带格式的文字后，程序自动用纯文本替换剪贴板内容；粘贴采用目标应用的样式。
- 右键托盘图标，顶部显示不可点击的监听状态（绿点“监听中”/灰点“空闲”）；下方可勾选“开启监听”、打开设置或退出。菜单开关与设置窗口同步，即时保存。切换监听开关后菜单保持展开，勾选及状态立即刷新；点击外部或按 Esc 收起，选择“设置”或“退出”按正常菜单行为处理。
- 双击图标打开设置；再次运行程序也会打开已有实例的设置。
- 设置保留“监听剪贴板”“特殊清理”和“开机自启动”三行。点击“特殊清理”右侧扳手打开独立配置窗口，所有选项修改后立即保存。
- 设置右下角绿色圆点旁显示“监听中”，灰色圆点旁显示“空闲”。修改监听开关后即时更新，托盘菜单切换也会同步。
- 关闭设置继续后台运行；退出程序需要使用托盘菜单。
- 开机启动默认关闭，不需要管理员权限。

“监听剪贴板”控制程序运行期间是否处理新复制的内容，取消即暂停；“开机自启动”控制进入 Windows 桌面后是否自动运行程序，省去手动双击。两者独立，自动启动会沿用上次保存的清洗/暂停状态，并非在登录前处理剪贴板。

“特殊清理”是额外规则的总开关，默认关闭。关闭后保留已选规则，也可以提前点击扳手配置；重新开启沿用原组合。基础去格式仍由“监听剪贴板”控制。旧版启用的 `CleanMixed` 自动沿用为“特殊清理＋移除图片＋移除文件附件”，不会自动开启文字处理规则。

### 特殊清理规则

配置窗口提供 18 个可组合选项，悬停可查看说明：

| 分组 | 独立规则 |
| --- | --- |
| 空格 | 删除每行开头空格、删除每行结尾空格、连续空格合并为一个、删除所有普通空格 |
| 特殊空白 | 全角空格转普通空格、不换行空格转普通空格、Tab 转一个普通空格、删除 Tab |
| 空行 | 删除文本开头空行、删除文本结尾空行、连续空行合并为一个、删除所有空行 |
| 换行 | 换行转一个普通空格、删除所有换行 |
| 隐藏字符 | 删除零宽空格（U+200B）、删除 BOM 字符（U+FEFF） |
| 图片与文件 | 移除图片、移除文件附件 |

文字规则顺序固定为：特殊空白/指定隐藏字符处理 → 每行首尾空格 → 空行 → 换行 → 连续空格合并/删除。CRLF 作为一个换行处理，也支持单独 CR 和 LF。只有普通空格或 Tab 的行也算空行；其他特殊空白需先勾选转换。Tab 的转换与删除互斥，换行的转换与删除互斥；删除全部空格/空行优先于对应的合并规则。已经是纯文本的内容也可按选定规则清理；内容无需改变时不会重复写回。组合表情使用的零宽连接符 U+200D 保留。

图片与文件分别移除，未勾选的已支持媒体内容会暂存在内存中并随文字写回。支持 DIB/DIBV5、位图、增强图元、PNG/JPEG/GIF/TIFF/WebP 等已识别图片格式，以及文件路径列表、Shell IDList 和常见拖放元数据。遇到无法可靠保留的混合格式（例如未知自定义格式、需保留的调色板/旧式图元）或虚拟文件/OLE 对象，整次跳过，不猜测其数据结构。媒体内存副本仅用于本次写回，不保存历史。纯图片、纯文件及空文本附带媒体保持原样；不删除磁盘文件、不执行 OCR、不读取文件正文。

## 构建

当前项目使用 MinGW-w64 GCC、windres 和 Python 3（仅用于复制图标资源，成品不需要 Python）。

正式图标为灰白复制纸张与浅金扫把，暂停时扫把变灰。源文件及多尺寸 ICO 位于 `assets/`；修改 SVG 后可用 `python tools/render_icons.py` 重新生成图标（仅此步骤需要 CairoSVG 和 Pillow）。常规构建直接使用已生成的 ICO，无须安装图像库。

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
.\dist\clear-copy.exe
# 直接显示设置：
.\dist\clear-copy.exe --settings
```

发布版会去除调试符号。`build.ps1 -Debug` 可生成带调试信息的版本。重新构建前先退出正在运行的程序。

目标：Windows 10 / 11 x64。当前使用 MinGW-w64 GCC 8.1 构建；API 全部来自 Windows。清洗逻辑和托盘共用 Windows 消息循环，空闲时不轮询剪贴板。

## 行为与边界

- 基础去格式保留 Unicode 文本、空格和换行，移除 HTML、RTF 等附加格式。额外文字修改仅在“特殊清理”及对应规则开启时执行。
- 默认跳过带图片或文件的混合剪贴板；开启特殊清理后，仅在存在非空 Unicode 文本且可安全处理其附带格式时执行。
- 表格和图文等内容使用源应用提供的纯文本表示；附带图片/文件分别由对应规则控制。只嵌入 HTML 内部、未独立提供的图片不能单独保留。
- 非 Unicode 文本、无终止符、超过 64 MiB 的文本数据不处理。
- 清洗是复制后的异步处理；极快粘贴、剪贴板长时间被占用等情况，不能保证本次已经清洗完成。
- 剪贴板忙时最多短暂重试约 300 ms；重试会重新检查剪贴板版本，不缓存旧文字写回。
- 自动清洗影响全局剪贴板。需要保留原格式时，请先从托盘暂停。
- 不模拟键盘、不接管粘贴快捷键，不上传或持久化剪贴板内容。

设置存放在 `HKCU\Software\ClearCopy`（`Enabled`、`SpecialEnabled`、`SpecialRules`）；用户启用开机启动后，会在 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中增加 `ClearCopy`。程序位置改变后，应关闭再重新开启该选项。删除前先关闭开机启动并退出程序。

## 验证

`python tests/integration.py` 对相同生产 C 源码及资源执行剪贴板、暂停、设置即时保存与关闭、单实例与退出验证。测试启动器先完成 DLL 加载再切换到独立 Windows 窗口站和桌面，使用隔离的系统剪贴板，不触碰当前桌面的剪贴板。测试会临时修改并恢复当前用户的 ClearCopy 设置；开机启动操作重定向到每次运行独立的测试注册表路径，结束后清理，不修改真实开机启动项。运行测试前先退出已有程序。
